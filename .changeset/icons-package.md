New package: `@greese/icons`, a small set of line icons as React components (Search, Plus, Trash, Star, Heart, Home, Bell, User, Sun, Moon, Document, Folder, Check, Close, Chevron, Menu, Info, ArrowRight). Sized to text (`1em`), inline on the text's baseline, and drawn in `currentColor`; decorative unless given a `title`; tree-shakable (about 0.3 kB for one); `createIcon(name, d)` makes matching icons. Optional: `@greese/react` doesn't depend on it.
