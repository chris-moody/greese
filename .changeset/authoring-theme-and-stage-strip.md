`AuthoringTheme`: the default authoring theme every editor app wraps itself in, with dense text controls and field names in the code face. The stylesheet opens with greese's layer order, so it holds whatever loads first. The stage's context bar scrolls when its controls overflow, every stage control has a tooltip, Stage color drops its label, and the layout's Save is an icon button.
