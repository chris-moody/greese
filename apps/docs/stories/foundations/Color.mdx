# Color

GreeseUI's colors come in two layers:

- **Roles**, such as `primary`, `surface` and `negative`. Components use
  these, they change with the color scheme, and a theme sets them.
- **The palette**: 22 hues in 11 shades each, from `50` (lightest) to `999`
  (darkest), like MUI's `colors`. The roles are built from it, and you can use
  it anywhere a color goes, instead of a hex literal.

## Roles

The brand colors come in order: `primary`, `secondary`, `tertiary` and
`accent`. Each has a `-strong` shade (hover, pressed) and a `-content`
color for text and icons drawn on it, which meets WCAG AA (at least 4.5:1)
against it in both schemes; the tables show each ratio.

`primary` is the color components use for interactive emphasis: solid
buttons, links, selection, and the focus ring, which follows it. Setting
`primary` rebrands every component. When a theme sets a brand color,
`createTheme()` (and the SCSS kit's `tokens()`) derive its `-content` and
`-strong` colors unless you set them too.

Each role is a custom property, `var(--greese-color-<role>)`, and
`token(color, <role>)` in the SCSS kit.

### As tones

Every component with a `tone` prop takes the brand roles: `tone="primary"`
(the default where there is one), `"secondary"`, `"tertiary"` or `"accent"` on Button, IconButton, ToggleButton, Badge,
Chip, Text, Heading, Link, Alert, Toast, Status, ChatBubble, Step, MenuItem
and Stat.

```tsx
<Button tone="secondary">Upgrade</Button>
<Badge tone="tertiary">Beta</Badge>
<Chip tone="accent">Featured</Chip>
```

## Using the palette

The same color in each place you'd write one:

| Where                          | Write                                              |
| ------------------------------ | -------------------------------------------------- |
| `createTheme()`, TypeScript    | `palette.lavender[600]`, or `import { lavender }`  |
| The SCSS kit, and Theme Studio | `lavender-600`, or `greese.palette(lavender, 600)` |
| CSS                            | `var(--greese-lavender-600)`, with `palette.css`   |

```tsx
import { createTheme, palette } from '@greese/ui'

export const brand = createTheme({
  name: 'brand',
  color: {
    primary: { light: palette.lavender[600], dark: palette.lavender[400] },
    primaryStrong: { light: palette.lavender[700], dark: palette.lavender[300] },
  },
})
```

```scss
@use 'pkg:@greese/ui/scss/kit' as greese;

@include greese.tokens(
  (
    color: (
      primary: (
        light: lavender-600,
        dark: lavender-400,
      ),
      secondary: (
        light: ruby-600,
        dark: ruby-400,
      ),
    ),
  )
);
```

**Costs.** In TypeScript and SCSS a palette color costs nothing extra. The
TypeScript palette exports each hue separately, so a bundle keeps only the
hues it imports. The SCSS kit writes the color itself into your CSS. The CSS
variables are a separate, opt-in stylesheet of 242 colors (about 2 kB
compressed), so `tokens.css` doesn't carry them:

```ts
import '@greese/ui/palette.css'
```

The palette doesn't change with the color scheme: `lavender-600` is the same
color in light and dark. For colors that should adapt, use a role, or give
a light/dark pair as above.
