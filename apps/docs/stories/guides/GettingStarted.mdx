# Getting started

```bash
npm install @greese/react
```

This also installs `@greese/ui`, the framework-free CSS and tokens it renders,
and `@greese/js`, for the `greese` prop. Requires React 19.

Import the stylesheet once, at your app root:

```tsx
import '@greese/react/base.css' // optional: reset + body defaults, if GreeseUI owns the page
import '@greese/react/styles.css' // tokens + every component
```

Then use components anywhere. Layout and display components are server-component
safe; interactive ones are marked `'use client'`.

No provider is needed to use GreeseUI: the styles load once and every component works. `ThemeProvider` is optional (see Guides/Theming). Reach for it only to apply a `createTheme()` theme, or to force a color scheme, on all or part of the page.

```tsx
import { Button, Stack, TextField } from '@greese/react'

export const SignIn = () => (
  <Stack gap={4} maxW="24rem">
    <TextField label="Email" type="email" name="email" required />
    <Button type="submit" fullWidth={{ xs: true, sm: false }}>
      Sign in
    </Button>
  </Stack>
)
```

## Without a framework

The CSS is its own package, `@greese/ui`, with no dependencies. Use it from
plain HTML, or under a framework that has no GreeseUI package yet:

```bash
npm install @greese/ui
```

```html
<link rel="stylesheet" href="node_modules/@greese/ui/dist/greese.css" />

<button class="greese-Button greese-Button--solid">Save changes</button>
```

Every component's classes, parts, modifiers and state attributes are listed
in its Styling section, and they're a public contract: the React components
render exactly these. Native elements (`<dialog>`, `<details>`, form controls)
work as they are; widgets with keyboard behaviour (Tabs, Combobox, Menu…) also
need JavaScript, which comes with the framework packages. With a bundler,
`import '@greese/ui/styles.css'` does the same as the link.

## Only the CSS you use

`styles.css` is about 23 kB brotli for everything. To ship less, import per-component
stylesheets instead. Each one pulls in the shared core and the components it builds
on, and bundlers de-duplicate the shared imports:

```tsx
import '@greese/react/css/Button.css'
import '@greese/react/css/TextField.css'
import '@greese/react/css/Dialog.css' // also brings IconButton, Button, VisuallyHidden
```

## Dark mode without a flash

The scheme follows the OS by default. To let users choose, add the pre-paint script
to `<head>` and call `useColorScheme()`:

```tsx
import { getSchemeScript, useColorScheme } from '@greese/react'

;<script dangerouslySetInnerHTML={{ __html: getSchemeScript() }} />

const { setScheme } = useColorScheme()
setScheme('dark') // 'light' | 'dark' | 'system'
```
