# Migrating from MUI

GreeseUI keeps MUI's ergonomics (responsive props, a theme, a broad component set) and
drops its runtime. Most code ports with renames.

| MUI                                                           | GreeseUI                                                               | Notes                                                                                                           |
| ------------------------------------------------------------- | ---------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `<Box sx={{ p: 2 }}>`                                         | `<Box p={2}>`                                                          | Typed style props instead of `sx`; `p={2}` is `0.5rem` (GreeseUI scale `0`–`8`), or pass any length: `p="16px"` |
| `<Stack spacing={2} direction={{ xs: 'column', md: 'row' }}>` | `<Stack gap={4} direction={{ xs: 'column', md: 'row' }}>`              | `gap` uses CSS gap; same breakpoint keys and values                                                             |
| `<Grid container spacing={2}><Grid size={{ xs: 12, md: 6 }}>` | `<Grid container columns={12} gap={4}><Grid size={{ xs: 12, md: 6 }}>` | The same shape. Plus `minChildWidth` and `containerQueries`                                                     |
| `<Container maxWidth="lg">`                                   | `<Container size="lg">`                                                |                                                                                                                 |
| `<Typography variant="h1">`                                   | `<Heading level={1}>` / `<Text size="lg">`                             | Outline level and size are separate                                                                             |
| `<Button variant="contained" color="error">`                  | `<Button variant="solid" tone="negative">`                             | `outlined` → `outline`, `text` → `ghost`, plus `soft`                                                           |
| `<IconButton aria-label="Close">`                             | `<IconButton label="Close">`                                           | Label is required                                                                                               |
| `<TextField label error helperText>`                          | `<TextField label error description>`                                  | `error` is the message itself                                                                                   |
| `<Select>` + `<MenuItem>`                                     | `<Select>` + `<option>`                                                | Native select: platform picker on phones                                                                        |
| `<Autocomplete options>`                                      | `<Combobox options>`                                                   | Single value; `allowCustomValue` for free text; `onInputChange` for async                                       |
| `<TextField type="number">`                                   | `<NumberField min max step>`                                           | Spinbutton on a text input: no wheel or locale surprises                                                        |
| `<DatePicker>` (MUI X)                                        | `<DateField>`                                                          | Native date/time inputs and platform pickers; no calendar bundle                                                |
| `<ToggleButtonGroup exclusive>`                               | `<SegmentedControl>` + `<Segment>`                                     | Native radios underneath                                                                                        |
| `<Table>` + `TableHead`/`TableRow`/`TableCell`                | Same names, plus `TableHeaderCell`                                     | `stackBelow` turns rows into cards on phones                                                                    |
| `<FormControlLabel control={<Checkbox />}>`                   | `<Checkbox label="…">`                                                 | Same for Switch and Radio                                                                                       |
| `<Dialog open onClose>`                                       | `<Dialog open onOpenChange title>`                                     | Native `<dialog>`; `title` required                                                                             |
| `<Drawer anchor="right">`                                     | `<Drawer placement="end">`                                             | Responsive placement: `{ xs: 'bottom', md: 'end' }`                                                             |
| `<Menu anchorEl>`                                             | `<Menu trigger={<Button>…</Button>}>`                                  | No anchor refs: the trigger is the anchor                                                                       |
| `<Snackbar>`                                                  | `toast({ title })` + `<Toaster />`                                     |                                                                                                                 |
| `<Tabs value onChange>` + `<Tab>`                             | `<Tabs value onValueChange>` + `TabList`, `Tab`, `TabPanel`            |                                                                                                                 |
| `<Accordion>`                                                 | `<Accordion>` + `AccordionItem`                                        | Native `<details>`; `exclusive` for one-open                                                                    |
| `<Chip onDelete>`                                             | `<Chip onRemove>`                                                      |                                                                                                                 |
| `<CircularProgress>` / `<LinearProgress>`                     | `<Spinner>` / `<Progress>`                                             |                                                                                                                 |
| `<CircularProgress variant="determinate">`                    | `<RadialProgress value>`                                               |                                                                                                                 |
| `<Rating>`                                                    | `<Rating label>`                                                       | Native radios; `readOnly` for fractions                                                                         |
| `<Stepper activeStep orientation>` + `<Step>`                 | `<Steps current>` + `<Step>`                                           |                                                                                                                 |
| `<Timeline>` (MUI Lab)                                        | `<Steps direction="vertical" markers="dots">` + `<Step prefix>`        | No `current`: steps are events in their own tones                                                               |
| `<SpeedDial>` + `<SpeedDialAction>`                           | Same names                                                             | Popover API: Escape and click-outside built in                                                                  |
| `<List>` + `<ListItem>`                                       | `<List>` + `<ListItem start title description end>`                    |                                                                                                                 |
| `<BottomNavigation>`                                          | `<Dock>` + `<DockItem>`                                                |                                                                                                                 |
| `useMediaQuery(theme.breakpoints.up('md'))`                   | `useBreakpointValue({ xs: false, md: true })`                          | Prefer responsive props                                                                                         |
| `createTheme({ palette })` + `ThemeProvider`                  | `createTheme({ name, color })` + `ThemeProvider`                       | Themes are static CSS; schemes via `useColorScheme`                                                             |
| `import { blue } from '@mui/material/colors'`                 | `import { blue } from '@greese-ui/tokens'`                             | `50`–`900` plus `999`, no `A100`–`A700`                                                                         |
| `styled(Button)(...)`                                         | A class name and CSS                                                   | Your unlayered CSS beats library layers                                                                         |

## Things that work differently

- **No `sx`.** Use typed style props, a class, or the component's CSS variables.
- **Spacing scale.** GreeseUI tokens are `0`–`8` (`4` = `1rem`); MUI multiplies by 8px.
- **Overlays need no portals or z-index:** they live in the browser's top layer.
- **Icons are yours:** pass any SVG component; nothing is bundled.
